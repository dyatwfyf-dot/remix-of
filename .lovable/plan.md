# ربط عمود المصروفات في الحساب الجاري بتبويب المصروفات

## الهدف
كل مبلغ يُسجَّل في عمود «المصروفات» في الحساب الجاري يُرحَّل تلقائياً إلى تبويب المصروفات: في **شهر التاريخ نفسه**، وفي **البند المناسب** حسب الكلمات الواردة في «البيان». يتغير الإجمالي فوراً عند إضافة قيد أو تعديله أو حذفه.

## قواعد التوجيه (قابلة للتوسعة)
| كلمة في البيان | البند في تبويب المصروفات |
|---|---|
| مكافأة / مكافاة / مكافآت | المكافآت |
| بدل امتحان / بدل اختبار / عمل إضافي / إضافي | أجور العمل الإضافي |
| بدل طبيعة عمل | بدل طبيعة العمل |
| بدل سكن / بدل ريف / بدل مظهر / بدل تحديث | البند المطابق |
| راتب / مرتبات | المرتبات الأساسية |
| أجور تعاقدية / متعاقد | أجور تعاقدية ومؤقتة |
| مياه / ماء | مياه |
| كهرباء / إنارة | إنارة |
| قرطاسية / أدوات مكتبية / طباعة / مطبوعات | أدوات كتابية ومكتبية |
| بريد / اتصالات / إنترنت / رصيد | البريد والاتصالات |
| ضيافة / احتفال / مؤتمر | مؤتمرات واحتفالات وضيافة |
| نظافة | نفقات النظافة |
| نقل / مواصلات / انتقالات | انتقالات داخلية |
| إيجار | إيجار المباني |
| تدريب | نفقات التدريب المحلي |
| أدوية / مستلزمات طبية | أدوية ومستلزمات طبية |
| وقود / ديزل / بترول / زيوت | وقود وزيوت |
| صيانة | صيانة وقطع غيار الآلات والمعدات والأثاث |
| غير ذلك | نفقات أخرى (السلع والخدمات) |

- الكلمات الأطول/الأدق تُفحص أولاً (مثلاً «بدل امتحان» قبل «بدل»).
- يتم توحيد الهمزات والتاء المربوطة قبل المطابقة.

## ما سيراه المستخدم
- في تبويب المصروفات: خانة «الفعلي» لكل بند وشهر = المدخل يدوياً + المرحَّل من الحساب الجاري، ومجاميع الفصول والأبواب تتحدث تلقائياً.
- علامة صغيرة/تلميح بجانب الخلية المرحَّلة توضح أن جزءاً منها من الحساب الجاري.
- لوحة صغيرة «قيود مرحّلة إلى نفقات أخرى» لعرض القيود التي لم تُعرف كلماتها لمراجعتها.
- الطباعة والتصدير في تبويب المصروفات يشملان المبالغ المرحّلة.

## التفاصيل التقنية
- ملف جديد `src/lib/expenseMapping.ts`: قائمة القواعد (كلمات ← اسم البند في `expensesSchema.json`)، دالة `normalizeArabic`، ودالة `mapDescriptionToRow(desc)` تعيد فهرس الصف.
- دالة `buildPostedExpenses(accounts, year)` تُرجع `Record<"month-rowIdx", number>` بجمع `expense` حسب شهر `date` (يتجاهل الرصيد الافتتاحي والمبالغ الصفرية).
- `ExpensesTab.tsx`: قراءة `accounts` من `useStore`، وفي `monthlyLeaves` إضافة المرحَّل إلى `r` لكل خلية قبل `computeAggregates`، دون تغيير بيانات التخزين اليدوية `expenses-data-v1`.
- لا تعديل على `AccountTab.tsx` أو على منطق الحساب الجاري.
- تسجيل قاعدة في `AGENTS.md`: الترحيل محسوب لحظياً من الحساب الجاري ولا يُخزَّن.
